版本 5.54（2025 年 6 月）
=======================

添加了 Java Code作。

更新了 JavaScript作以支援返回所有變數類型 - 使用 mdOutput（value）。

添加了以 JSON 格式 {vjson=}、{lvjson=} 輸出陣列和字典變數的選項（以使其在 JavaScript作中更易於使用）。

添加了 App Activity Launched/Closed 觸發器。

更新了「配置快速磁貼」作，以支援將磁貼設置為無法與之交互的非活動狀態。

更新了 HTTP 請求作，以在內容正文中添加對動態檔名/本地 uri 的支援。

添加了“Apply Auto Focus（應用自動對焦）”以拍照作的選項。

添加了「創建 GUID」魔術文本以創建全域唯一標識碼。

為浮動按鈕觸發器和浮動文本作添加了“按下時振動”選項。

添加了在查看單個巨集的 System Log 時清除該巨集的系統日誌的功能（通過 edit macro 螢幕）。

在使用 System Log Entry 觸發器時，為日誌文本添加了特定於上下文的魔術文本。

添加了在 Wait Until Trigger作中使用變數值作為超時的選項。

導出的巨集和類別現在將包含任何關聯的全域變數作為導出的一部分。

修復了除非安裝了説明應用程式，否則配置 Wifi 狀態更改觸發器不允許選擇 SSID 的問題。

修復了在更新引用的變數時 scene slider 無法正確更新範圍的問題。

添加了對 Marathi 語言到 Speak Text作的支援。

修復了將位置共用到變數不支援保存到字典/陣列元素的問題。

添加了在使用 HTTP Server Request 觸發器時禁用網頁的設置。

其他小修復。

-- 場景改進 --

添加了 Horizontal Divider 元件。

添加了對單擊場景 Slider 元件上的值並通過對話框輸入數字的支援。

添加了對場景文本輸入元件中密碼輸入的支援。

為場景 Switch 和 Checkbox 元件添加了拆分對齊選項。

添加了在使用對話框或疊加選項時在 Scenes 上設置圓角的選項。

Scene Slider 現在支援在開始和結束（或無）處顯示值標籤。

Scene Slider 現在支援步長值。

Scene Text 現在支援用於指定文字大小的魔術文本值。

場景文本現在支援 HTML 格式選項。

Scene Text 現在支援最大行數和縮放以適應選項。

現在，所有場景項都支援可綁定到布爾變數的可見性狀態。

場景切換現在支持單獨的文本顏色、關閉顏色和打開顏色。

Scene Button 現在支援切換布爾變數。

修復了從作塊運行且不使用 block next actions by default 選項時，scene 不會正確更新變數的問題。
