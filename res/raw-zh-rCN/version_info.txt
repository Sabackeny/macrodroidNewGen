当使用宏机器人作为默认助手时，谷歌需要此更新来添加识别器服务。

版本 5.24（2022 年 5 月）
==========================

添加了“读取屏幕内容”操作。

添加了屏幕内容触发器。

添加了“从文件读取”操作。

添加了“类别启用/禁用”约束。

添加了导出日志操作。

添加了在 UI 交互单击中手动输入视图 ID 的选项。

为不允许在后台使用 MacroDroid 设置音量的设备，为设备添加了“设置音量”的“地名”选项。

添加了弹出消息操作的选项以取消上一个弹出窗口（例如，对于第二次倒计时很有用）

向“消息对话框”和“选项对话框”操作添加了选项，以防止后退按钮关闭对话框。

在 WebHook 触发器中添加了对设置字典/数组变量条目的支持。

报告错误功能现在包括添加屏幕截图的功能。

添加了对重命名宏机器人抽屉中快捷方式的支持。

宏文本抽屉现在支持通过向上滑动和/或向下滑动手势打开的选项。

其他小的修复和调整。

版本 5.23（2022 年 4 月）
==========================

添加了字典和数组变量类型（仅限 Pro 用户）。

添加了迭代字典/数组操作，可用于循环访问字典/数组中的所有元素。

添加了 JSON 解析操作。

将“设置快速设置磁贴状态”操作更改为“配置快速磁贴”操作，以允许对图标和标签进行其他设置。

向 UI 交互操作添加了手势序列选项，以启用复杂的手势，如轻扫锁定模式。

在 UI 交互配置屏幕中添加了切换触摸位置叠加的选项。

添加了为 Logcat 触发器启用/禁用单个缓冲区的功能。

添加了 IP 地址约束。

添加了网络钩子基本网址的魔术文本。

向操作阻止列表屏幕添加了搜索功能。

添加了以HTML格式导出系统日志的选项，以便它可以输出与应用程序中显示的颜色相同的颜色编码。

在“编辑宏”和“动作块”屏幕中添加了剪切选项，以允许完整的剪切、复制和粘贴功能。

操作块“测试操作”现在将在运行时显示输出变量的摘要。

修复了宏调用方法在所有情况下都无法正常工作的问题。

修复了“未发生事件”条件在“日历”约束中无法正常工作的问题。

修复了 HTTP 请求操作中的文件名无法正确处理幻文本值的问题。

修复了取消父宏时操作块中的操作不会取消的问题。

修复了某些设备上壁纸可能无法正确旋转的问题。

其他小的修复和调整。

为选项对话框添加了“忽略（取消宏）”选项，以防止在选中后运行任何进一步的操作。

添加了在全局变量屏幕上按类型筛选变量的功能。

为基于呼叫/短信的触发器添加了排除选项，并在选择对话框中添加了可搜索的联系人姓名。

修复了将 tasker 数组值组合成单个字符串有时会使元素顺序错误的问题。

修复了与附近设备共享在 Android 12 设备上并不总是有效的问题。

修复了为“语音输出”操作选择全局变量可能会设置错误变量的问题。

修复了蓝牙信标触发器可能最终为单个事件触发多次的问题。

修复了地理围栏在搜索或放大/缩小时无法以正确区域为中心的问题。

修复了无线网络 SSID 列表可能包含重复条目的问题。

修复了局部变量中很长的字符串可能会阻止访问 OK 按钮的问题。

修复了在某些情况下设置宏机器人图标无法更新图标的问题。

修复了日历约束中的全天事件在不同时区无法正常工作的问题。

许多其他小的修复和调整。
