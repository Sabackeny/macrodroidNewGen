版本 5.54（2025 年 6 月）
=======================

添加了 Java Code作。

更新了 JavaScript作以支持返回所有变量类型 - 使用 mdOutput（value）。

添加了以 JSON 格式 {vjson=}、{lvjson=} 输出数组和字典变量的选项（以使其在 JavaScript作中更易于使用）。

添加了 App Activity Launched/Closed 触发器。

更新了“配置快速磁贴”作，以支持将磁贴设置为无法与之交互的非活动状态。

更新了 HTTP 请求作，以在内容正文中添加对动态文件名/本地 uri 的支持。

添加了“Apply Auto Focus（应用自动对焦）”以拍照作的选项。

添加了“创建 GUID”魔术文本以创建全局唯一标识符。

为浮动按钮触发器和浮动文本作添加了“按下时振动”选项。

添加了在查看单个宏的 System Log 时清除该宏的系统日志的功能（通过 edit macro 屏幕）。

在使用 System Log Entry 触发器时，为日志文本添加了特定于上下文的魔术文本。

添加了在 Wait Until Trigger作中使用变量值作为超时的选项。

导出的宏和类别现在将包含任何关联的全局变量作为导出的一部分。

修复了除非安装了帮助应用程序，否则配置 Wifi 状态更改触发器不允许选择 SSID 的问题。

修复了在更新引用的变量时 scene slider 无法正确更新范围的问题。

添加了对 Marathi 语言到 Speak Text作的支持。

修复了将位置共享到变量不支持保存到字典/数组元素的问题。

添加了在使用 HTTP Server Request 触发器时禁用网页的设置。

其他小修复。

-- 场景改进 --

添加了 Horizontal Divider 组件。

添加了对单击场景 Slider 组件上的值并通过对话框输入数字的支持。

添加了对场景文本输入组件中密码输入的支持。

为场景 Switch 和 Checkbox 组件添加了拆分对齐选项。

添加了在使用对话框或叠加选项时在 Scenes 上设置圆角的选项。

Scene Slider 现在支持在开始和结束（或无）处显示值标签。

Scene Slider 现在支持步长值。

Scene Text 现在支持用于指定文本大小的魔术文本值。

场景文本现在支持 HTML 格式选项。

Scene Text 现在支持最大行数和缩放以适应选项。

现在，所有场景项都支持可绑定到布尔变量的可见性状态。

场景切换现在支持单独的文本颜色、关闭颜色和打开颜色。

Scene Button 现在支持切换布尔变量。

修复了从作块运行且不使用 block next actions by default 选项时，scene 不会正确更新变量的问题。
