Версія 5.54 (червень 2025 р.)
=======================

Додано дію Java Code.

Оновлено дію JavaScript для підтримки повернення до всіх типів змінних - Використовуйте mdOutput(value).

Додана опція для виведення масиву та змінних словника у форматі JSON {vjson=}, {lvjson=} (для полегшення їх використання в діях JavaScript).

Додано активатор запуску та закриття активності в додатках.

Оновлено дію «Налаштувати швидку плитку» для підтримки встановлення плитки в неактивний стан, коли з нею неможливо взаємодіяти.

Оновлено дію HTTP-запиту для додавання підтримки динамічних імен файлів/локального uri в тілі вмісту.

Додано опцію «Застосувати автофокус» для виконання дії «Знімок».

Додано магічний текст "Create GUID" для створення глобально унікального ідентифікатора.

Додано опцію «Вібрувати при натисканні» до тригера «Плаваюча кнопка» та дії з плаваючим текстом.

Додано можливість очищати системний журнал для окремого макросу під час перегляду системного журналу для цього макросу (за допомогою екрана редагування макросу).

Додано специфічний для контексту магічний текст для тексту журналу при використанні активатора введення системного журналу.

Додано можливість використовувати значення змінної для тайм-ауту в дії «Чекати до спрацьовування».

Експортовані макроси та категорії тепер міститимуть усі пов'язані глобальні змінні в рамках експорту.

Виправлено проблему, через яку налаштування тригера зміни стану Wi-Fi не дозволяло вибрати SSID, якщо не було встановлено допоміжну програму.

Виправлено проблему, через яку повзунок сцени неправильно оновлював діапазон при оновленні змінних, на які посилаються.

Додано підтримку дії «Говорити текстом» мовою маратхі.

Виправлено проблему, через яку функція «Поділитися місцем розташування зі змінною» не підтримувала збереження в елементі словника/масиву.

Додано налаштування для вимкнення веб-сторінки при використанні тригера запиту сервера HTTP.

Інші незначні виправлення.

-- Удосконалення сцени --

Додано компонент горизонтального дільника.

Додано підтримку натискання значення на компоненті слайдера сцени та введення числа за допомогою діалогового вікна.

Додано підтримку введення пароля у компоненті введення тексту сцени.

Додано опцію розділеного вирівнювання для компонентів Scene Switch та Checkbox.

Додано опцію для встановлення заокруглених кутів у сценах при використанні діалогового вікна або опції накладання.

Scene Slider тепер підтримує відображення мітки зі значенням на початку та в кінці (або без неї).

Scene Slider тепер підтримує значення кроків.

Функція «Текст сцени» тепер підтримує магічні значення тексту для визначення розміру тексту.

Текст сцени тепер підтримує опцію форматування HTML.

Функція «Текст сцени» тепер підтримує максимальну кількість ліній і параметр масштабування за розміром.

Усі елементи сцени тепер підтримують стан видимості, який може бути прив'язаний до булевої змінної.

Scene Switch тепер підтримує роздільний колір тексту, вимикає колір і вмикає колір.

Кнопка «Сцена» тепер підтримує перемикання булевої змінної.

Виправлено проблему, через яку сцена не оновлювала змінні відповідно, коли запускалася з блоку дій і не використовувала опцію наступних дій блоку за замовчуванням.
