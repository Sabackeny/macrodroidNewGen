버전 5.10
============

버그 수정 릴리스. 몇 가지 작은 문제와 드문 충돌을 수정합니다.

일부 누락된 권한에 대한 처리가 개선되었습니다.

버전 5.9
===========

자동 백업 화면에 클라우드 백업 기능이 추가되었습니다 (Pro 사용자 만 해당).

MacroDroid 포럼은 Tapatalk에서 더 깨끗한 자체 호스팅 포럼으로 옮겨졌습니다.

몇 가지 사소한 버그 수정.

버전 5.8
===========

Wi-Fi 액션을 설정하면 이제 Android 10 +에서 도우미 파일이 필요합니다 (Google 제한 앱 강제).

트리거 때까지 대기 작업이 추가되어 특정 트리거가 실행될 때까지 실행 중인 매크로가 일시 중지될 수 있도록 했습니다.

암호 / 핀으로 범주를 잠그는 옵션이 추가되었습니다.

전원 버튼 메뉴에 MacroDroid 매크로를 추가하는 기능 추가 (Android 11에만 해당)

팝업 메시지 동작에 텍스트 색상 옵션이 추가되었습니다.

'매크로 실행'작업에 대한 완료 될 때까지 대기 옵션이 추가되었습니다.

팝업 메시지 동작에 텍스트 색상 옵션과 아이콘 색조가 추가되었습니다.

이제 텍스트 말하기 작업을 통해 각 개별 작업 인스턴스에서 언어를 설정할 수 있습니다.

이제 캘린더 항목 추가 작업은 변수의 값을 기준으로 항목의 시간을 설정할 수 있도록 지원합니다.

마법 텍스트가 작동하지 않logcat_line 문제를 해결했습니다.

매크로 작업 취소로 인해 트리거될 때까지 대기 작업이 취소되지 않는 문제가 해결되었습니다.

중첩된 IF/ELSE 명령이 일부 엣지 케이스에서 예상대로 동작하지 않는 일부 논리 문제를 수정했습니다.

버전 5.7
===========

MacroDroid (홈 화면 타일)와 호환되는 타사 앱을 검색 / 공유하기위한 플러그인 목록이 추가되었습니다.

마지막으로 편집한 매크로에 빠르게 액세스할 수 있도록 홈 화면 타일이 추가되었습니다.

빠른 실행 매크로를 위한 홈 화면 타일이 추가되었습니다.

카메라 사용/비활성화 동작이 추가되어 장치의 모든 응용 프로그램에 대해 카메라를 비활성화할 수 있습니다.

오디오 버튼 시뮬레이션 옵션이 마지막으로 사용한 미디어 응용 프로그램을 제어하는 데 더 잘 작동하도록 미디어 동작 제어가 조정되었습니다.

일/시간 트리거를 사용하면 이제 특정 초 값을 설정할 수 있습니다.

변수 목록 화면에 검색 기능을 추가합니다.

버전 5.6
===========

비행기 모드 동작은 이제 Android 7 +의 루팅되지 않은 장치에서 수행 할 수 있습니다 (MacroDroid를 기본 보조 앱으로 설정하여).

응용 프로그램 시작 작업은 이제 패키지 이름 옵션(변수 등을 지원하는 마법 텍스트 포함)을 지원합니다.

이제 MacroDroid 변수 값을 Tasker 서식 스타일(%varname)을 사용하여 Tasker 플러그인에 전달할 수 있습니다.

알림 단추 모음 배경/색조 및 SMTP 설정은 이제 매크로를 내보낼 때 저장됩니다.

날씨 트리거 (및 날씨 특정 마법 텍스트)에 바람 방향 값을 추가했습니다.

정수 변수가 업데이트되어 이제 2,147,483,647> 값을 보유할 수 있도록 long 형식으로 뒷받침됩니다.

다른 사소한 수정 및 개선.
