Version 5.54 (juni 2025)
=======================

Åtgärden Java Code har lagts till.

JavaScript-åtgärden har uppdaterats för att stödja återgång till alla variabeltyper – Använd mdOutput(value).

Lade till alternativ för att mata ut matris- och ordboksvariabler i JSON-format {vjson=}, {lvjson=} (för att göra dem enklare att använda i JavaScript-åtgärd).

Lade till utlösaren Startad/Stängd för appaktivitet.

Åtgärden Konfigurera snabbpanel har uppdaterats för att stödja inställningen av en panel i ett inaktivt tillstånd där den inte kan interageras med.

HTTP-begärandeåtgärden har uppdaterats för att lägga till stöd för dynamiska filnamn/lokal URI i innehållstexten.

Lade till alternativet "Använd autofokus" för att ta bildåtgärd.

Magisk text "Skapa GUID" har lagts till för att skapa en globalt unik identifierare.

Lade till alternativet "Vibrera vid tryck" till utlösaren för flytande knapp och åtgärden flytande text.

Lade till möjlighet att rensa systemloggen för ett enskilt makro när du visar systemloggen för det makrot (via skärmen för att redigera makro).

Kontextspecifik magisk text har lagts till för loggtext när du använder utlösaren för systemlogginmatning.

Lade till ett alternativ för att använda variabelvärde för timeout i Vänta tills utlösaråtgärden.

Exporterade makron och kategorier kommer nu att innehålla alla associerade globala variabler som en del av exporten.

Åtgärdade ett problem där konfiguration av utlösare för ändring av wifi-tillstånd inte tillät val av SSID om inte hjälpappen var installerad.

Ett problem har åtgärdats där scenreglaget inte uppdaterade intervallet korrekt när refererade variabler uppdaterades.

Stöd har lagts till för marathi-språket för åtgärden Läs upp text.

Ett problem har åtgärdats där Share Location to variable inte hade stöd för att spara i ordliste-/matriselementet.

En inställning har lagts till för att inaktivera webbsidan när du använder utlösaren för HTTP-serverbegäran.

Andra mindre korrigeringar.
