Версія 5.53 (квітень 2025 р.)
============================

Додано дію Custom Scene для створення простих настроюваних інтерфейсів користувача.

Додано дію «Приховати власну сцену».

Екрани блоків редагувань макросів/дій тепер підтримують опцію меню для додавання роздільників.

Функція автоматичного резервного копіювання тепер дозволяє змінювати локальне місце зберігання резервних копій.

Оновлено дію «Операція з файлом» для додавання можливості вказувати шаблони папок (при копіюванні/переміщенні/видаленні папок)

Оновлено обмеження порівняння значень, щоб додати опцію порівняння масивів та словників, а також додано перевірки, якщо вони містять ключ/значення.

Оновлено обмеження «Виконання макросу» для підтримки введення імені макросу як тексту (включно з підтримкою магічного тексту).

Оновлено дію «Увімкнути/вимкнути категорії» для підтримки нової опції для включення всіх макросів у межах категорії (при включенні категорії).

Оновлено функцію «Текст для спільного доступу до MacroDroid», щоб додати новий контекстно-специфічний магічний текст для поля «Тема», яке встановлюється під час оприлюднення тексту.

Оновлено дію «Накладання анімації» для додавання опції примусового оновлення зображення (ігнорувати кеш).

Мінімальна підтримувана версія Android тепер Android 6 (Marshmallow).

Виправлено проблему, через яку спроба виконати кілька одночасних дій JavaScript із двигуном Jetpack могла зазнати невдачі.

Виправлено проблему, через яку проведення MacroDroid через перемикач додатків могло вбити макроси, які очікували на дію «Зачекайте, поки не спрацює».

Виправлено проблему, через яку дія «Підсумувати макроси» не додавала локальні змінні під час вибору параметра «усі змінні».

Додано опцію до тригера заходу сонця/сходу сонця для використання (або невикористання) будильника для забезпечення точного часу спрацьовування.

Додано опцію Вимкнути дію MacroDroid, щоб дозволити йому завжди вимикати MacroDroid (незалежно від налаштувань захисту паролем).

Версія 5.52 (березень 2025 р.)
============================

Додано тригер стану «Увімкнено NFC».

Змінено дію ввімкнення/вимкнення HotSpot, тому допоміжний файл більше не потрібен на Android 14+.

Додано опцію меню для ввімкнення/вимкнення ведення журналу для кожного окремого тригера, дії та обмеження.

Екран конфігурації геозон повертається до Open Street Maps на пристроях, які не мають сервісів Google.

Змінено дію «Взаємодія зі сповіщеннями», щоб вона знову могла працювати на пристроях Android 14+.

Оновлено обмеження «Увімкнено/Вимкнено макрос», щоб додати підтримку вказівки імені макросу в тексті (включно з підтримкою магічного тексту).

Оновлено дію «Отримати текст із View Id», щоб додати опцію збереження стану екрана до булевої змінної.

Додано підтримку тонування нетипових іконок віджетів.

Видалено плитку Додати майстер макросів.

Додано плитку блоку останніх відкритих дій.

Додано можливість підсумувати дію макросів для додавання всіх змінних, що використовуються макросом (локальний + глобальний).

Додано можливість встановити максимальну кількість рядків для змінної у панелі MacroDroid.

Додано опції меню вставки під час редагування списку умов у дії речення IF.

Додано опцію для примусового оновлення екрана до дій «Прочитати вміст екрана», «Отримати текст за ідентифікатором перегляду» та «Перевірити текст на екрані».

Виправлено проблему, через яку магічний текст {cell_connection_type} не відображав останній тип підключення клітинки при його зміні.

Виправлено проблему, через яку копіювання масиву/словника копіювання набору змінних не відображало всі підмасиви/словники.

Виправлено проблему, через яку тригер тривалого натискання значка MacroDroid не працював належним чином із обмеженням Trigger Fired.

Змінено службу спеціальних можливостей взаємодії з інтерфейсом користувача, щоб виправити проблеми, через які старий вміст екрана міг повертатися після оновлення екрана.

Змінено обмеження ввімкнення/вимкнення екрана, щоб спробувати виправити випадки, коли він повідомляє про увімкнення екрана, коли він вимкнений (наприклад, при підключенні до Android Auto).

Версія 5.50 (січень 2025 р.)
============================

Додано дію сканування SSID Wi-Fi.

Додано обмеження підключення USB-пристрою.

Додано дію «Підсумувати макроси/блоки дій».

Додано дію групи дій для полегшення групування, переміщення, копіювання та ввімкнення/вимкнення пов'язаних дій.

Додано підтримку функції скасування під час переупорядкування елементів на екранах «Редагувати макрос» і «Редагувати блок дій».

Додано підтримку спільного доступу до файлів резервних копій із хмарної резервної копії, щоб можна було легко отримати доступ до кожного файлу резервної копії без відновлення з нього.

Удосконалено спадні списки вибору блоків макросів/дій, щоб їх можна було шукати у випадках, коли доступно велику кількість опцій.

Оновлено дію «Плаваючий текст» для підтримки необов'язкової тіні (щоб зробити текст більш помітним при використанні прозорого тла)

Оновлено тригер «Відправлено SMS» для додавання можливості вказувати номер безпосередньо.

Оновлено дію «Накладання анімації» для підтримки використання змінних для визначення значень x, y, ширини та висоти анімації.

Оновлено дію «Показувати сповіщення» для підтримки введення магічного тексту для поля ідентифікатора.

Додано відсутні налаштування MacroDroid у файл резервної копії для полегшення відновлення.

Додано кнопку копіювання під час редагування запису змінної масиву/словника для отримання магічного тексту для повного шляху масиву/словника.

Виправлено рідкісну проблему, через яку плаваючі кнопки могли зависати в деяких випадках.

Виправлено проблему, через яку плаваючий текст міг блимати під час регулярного оновлення існуючого плаваючого тексту.

Інші незначні виправлення.

Удосконалено дію «Отримати контакти», завдяки якій вона правильно заповнюватиме кілька користувацьких записів телефону правильними користувацькими іменами.

Додано опції "Тестові дії" та "Тест макросу" до обмеження методу виклику макросу.

Додано можливість показувати записи підсловника у вигляді змінних словника тривалим натисканням на поле значення.

Додано підтримку показу вмісту словника на змінному екрані (тривале натискання на значення для увімкнення/вимкнення).

Змінено спосіб отримання магічного тексту {cell_connection_type}, щоб спробувати підвищити точність ідентифікації типу мережі.

Оновлено дію «Надіслати намір» для додано підтримку магічного тексту в полях «Дія», «Пакет» і «Клас».

Виправлено проблему, через яку дія «Скасувати дії макросу» не викликала активацію тригера завершення макросу.

Виправлено проблему, через яку відступи на маленьких плаваючих кнопках були неправильними.

Виправлено проблему з дією «Відкрити журнал викликів», яка не працювала на деяких пристроях.

Виправлено проблему, через яку обмеження порівняння значень не могло правильно порівнювати логічні значення в деяких мовах.

Виправлено проблему, через яку дія «Встановити зображення панелі кнопок» не оновлювала посилання на номер кнопки, коли кнопку переміщують ліворуч або праворуч на панелі кнопок.

Виправлено проблему з крайнім випадком, коли кілька тригерів у дії «Зачекайте, поки тригер» спрацьовували приблизно в один і той самий час і спричиняли неправильне виконання макросу.

Виправлено проблему, через яку дія «Записати у файл» могла змішувати порядок під час запису в той самий файл у швидкій послідовності.
