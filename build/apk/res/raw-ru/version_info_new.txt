Версия 5.54 (июнь 2025)
=======================

Добавлено действие Java Code.

Обновлено действие JavaScript для поддержки возврата ко всем типам переменных - используйте mdOutput(value).

Добавлена возможность вывода переменных массива и словаря в формате JSON {vjson=}, {lvjson=} (чтобы их было удобнее использовать в действии JavaScript).

Добавлен триггер «Запущено/закрыто действие приложения».

Обновлено действие "Настроить быструю плитку" для поддержки перевода плитки в неактивное состояние, в котором с ней невозможно взаимодействовать.

Обновлено действие HTTP-запроса для добавления поддержки динамических имен файлов/локального uri в теле содержимого.

Добавлена опция «Применить автофокус» для съемки изображения.

Добавлен магический текст «Создать GUID» для создания глобального уникального идентификатора.

Добавлена опция «Вибрация при нажатии» для триггера плавающей кнопки и действия с плавающим текстом.

Добавлена возможность очистки системного журнала для отдельного макроса при просмотре системного журнала для этого макроса (через экран редактирования макроса).

Добавлен контекстно-зависимый магический текст для текста журнала при использовании триггера системной записи в журнал.

Добавлена возможность использовать переменное значение для таймаута в действии Wait Until Trigger.

Экспортируемые макросы и категории теперь будут содержать все связанные глобальные переменные в рамках экспорта.

Исправлена ошибка, из-за которой настройка триггера изменения состояния Wifi не позволяла выбрать SSID, если не было установлено вспомогательное приложение.

Исправлена ошибка, из-за которой ползунок сцены неправильно обновлял диапазон при обновлении переменных, на которые ссылаются.

Добавлена поддержка языка маратхи в действии «Произнести текст».

Исправлена проблема, при которой Share Location to variable не поддерживал сохранение в элемент словаря/массива.

Добавлена настройка отключения веб-страницы при использовании триггера HTTP Server Request.

Другие мелкие исправления.

-- Улучшения сцены --

Добавлен компонент Горизонтальный разделитель.

Добавлена поддержка клика по значению на компоненте сцены Slider и ввода номера через диалог.

Добавлена поддержка ввода пароля в компоненте Text Entry сцены.

Добавлена возможность раздельного выравнивания для компонентов сцены Switch и Checkbox.

Добавлена возможность задавать закругленные углы на сценах при использовании диалогового окна или опции наложения.

Scene Slider теперь поддерживает отображение метки значения в начале и в конце (или не отображается).

Scene Slider теперь поддерживает значения шагов.

Scene Text теперь поддерживает магические значения текста для указания размера текста.

Текст сцены теперь поддерживает опцию форматирования HTML.

Текст сцены теперь поддерживает максимальное количество линий и опцию масштабирования по размеру.

Все элементы сцены теперь поддерживают состояние видимости, которое можно привязать к логической переменной.

Scene Switch теперь поддерживает отдельный цвет текста, выключение цвета и включение цвета.

Кнопка сцены теперь поддерживает переключение логической переменной.

Исправлена ошибка, из-за которой сцена не обновляла переменные должным образом при запуске из блока действий и отсутствии использования опции блокировать следующие действия по умолчанию.
