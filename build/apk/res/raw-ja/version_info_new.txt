バージョン 5.54 (2025 年 6 月)
=======================

Java Code アクションを追加しました。

すべての変数型に戻ることをサポートするように JavaScript アクションを更新しました - mdOutput(value) を使用します。

JSON形式の{vjson=}、{lvjson=}で配列変数と辞書変数を出力するオプションを追加しました（JavaScriptアクションで使いやすくするため。

アプリアクティビティの起動/終了トリガーを追加しました。

[クイック タイルの構成] アクションを更新し、タイルを操作できない非アクティブな状態に設定できるようにしました。

HTTP リクエストアクションを更新し、コンテンツ本文に動的ファイル名/ローカル URI のサポートを追加しました。

写真を撮るための「オートフォーカスの適用」オプションを追加しました。

グローバル一意識別子を作成するための「GUIDの作成」マジックテキストを追加しました。

フローティングボタントリガーとフローティングテキストアクションに「押したときにバイブレーション」オプションを追加しました。

個々のマクロのシステム・ログを表示するときに、そのマクロのシステム・ログをクリアする機能が追加されました (マクロの編集画面を使用)。

システムログエントリトリガーを使用する際のログテキストにコンテキスト固有のマジックテキストを追加しました。

Wait Until Trigger アクションのタイムアウトに変数値を使用するオプションを追加しました。

エクスポートされたマクロとカテゴリには、エクスポートの一部として関連するグローバル変数が含まれるようになりました。

Wifi State Change トリガーを設定すると、ヘルパー アプリがインストールされていない限り SSID を選択できない問題を修正しました。

参照される変数が更新されたときに、シーン スライダーが範囲を正しく更新しない問題を修正しました。

テキストの読み上げアクションにマラーティー語のサポートを追加しました。

変数への共有場所が辞書/配列要素への保存をサポートしない問題を修正しました。

HTTP Server Request トリガーの使用時に Web ページを無効にする設定を追加しました。

その他のマイナーな修正。

-- シーンの改善 --

Horizontal Divider コンポーネントを追加しました。

シーンのスライダーコンポーネントの値をクリックし、ダイアログで数値を入力するためのサポートが追加されました。

シーンのテキスト入力コンポーネントでのパスワード入力のサポートが追加されました。

シーンのスイッチコンポーネントとチェックボックスコンポーネントに分割配置オプションを追加しました。

ダイアログまたはオーバーレイオプションを使用するときにシーンに丸みを帯びた角を設定するオプションを追加しました。

Scene Slider で、開始時と終了時に値ラベルを表示 (または表示なし) できるようになりました。

Scene Slider がステップ値をサポートするようになりました。

シーンテキストは、テキストサイズを指定するためのマジックテキスト値をサポートするようになりました。

シーンテキストがHTMLフォーマットオプションをサポートするようになりました。

シーン テキストで、最大ライン数とサイズに合わせてスケール オプションがサポートされるようになりました。

すべてのシーンアイテムが、ブール変数にバインドできる可視性状態をサポートするようになりました。

Scene Switchは、個別のテキストカラー、スイッチオフカラー、スイッチオンカラーをサポートするようになりました。

Scene Button で、ブール変数の切り替えがサポートされるようになりました。

アクションブロックから実行し、デフォルトでブロックの次のアクションオプションを使用しない場合、シーンが変数を正しく更新しない問題を修正しました。
