버전 5.54(2025년 6월)
=======================

Java 코드 작업이 추가되었습니다.

모든 변수 유형으로의 반환을 지원하도록 JavaScript 작업이 업데이트됨 - mdOutput(value)를 사용합니다.

배열 및 딕셔너리 변수를 JSON 형식 {vjson=}, {lvjson=}으로 출력하는 옵션이 추가되었습니다(JavaScript 작업에서 더 쉽게 사용할 수 있도록).

앱 활동 실행/닫힘 트리거가 추가되었습니다.

타일을 상호 작용할 수 없는 비활성 상태로 설정하는 기능을 지원하도록 Configure Quick Tile 작업이 업데이트되었습니다.

콘텐츠 본문에서 동적 파일 이름/로컬 uri에 대한 지원을 추가하도록 HTTP 요청 작업이 업데이트되었습니다.

사진 작업을 수행하기 위해 '자동 초점 적용' 옵션을 추가했습니다.

전역적으로 고유한 식별자를 만들기 위해 'Create GUID' 매직 텍스트를 추가했습니다.

'Vibrate on Press' 옵션을 Floating Button 트리거와 Floating text 액션에 추가했습니다.

해당 매크로에 대한 시스템 로그를 볼 때 개별 매크로에 대한 시스템 로그를 지우는 기능이 추가되었습니다(매크로 편집 화면을 통해).

시스템 로그 항목 트리거를 사용할 때 로그 텍스트에 대한 컨텍스트별 매직 텍스트를 추가했습니다.

Wait Until Trigger 액션에서 타임아웃에 변수 값을 사용하는 옵션이 추가되었습니다.

이제 Exported Macros and Categories(내보낸 매크로 및 범주)에는 내보내기의 일부로 연결된 모든 전역 변수가 포함됩니다.

도우미 앱이 설치되지 않은 경우 Wi-Fi 상태 변경 트리거를 구성하면 SSID 선택이 허용되지 않는 문제가 해결되었습니다.

참조된 변수가 업데이트될 때 장면 슬라이더가 범위를 올바르게 업데이트하지 않는 문제가 수정되었습니다.

텍스트 말하기 작업에 대한 마라티어 지원이 추가되었습니다.

변수에 대한 위치 공유가 사전/배열 요소에 대한 저장을 지원하지 않는 문제가 수정되었습니다.

HTTP 서버 요청 트리거를 사용할 때 웹 페이지를 비활성화하는 설정이 추가되었습니다.

다른 사소한 수정 사항.

-- 장면 개선 --

수평 분할기 구성 요소가 추가되었습니다.

장면 슬라이더 구성 요소에서 값을 클릭하고 대화 상자를 통해 숫자를 입력하는 지원이 추가되었습니다.

장면 텍스트 입력 구성 요소에서 암호 입력에 대한 지원이 추가되었습니다.

장면 Switch 및 Checkbox 구성 요소에 대한 분할 정렬 옵션이 추가되었습니다.

대화 상자 또는 오버레이 옵션을 사용할 때 장면에서 둥근 모서리를 설정하는 옵션이 추가되었습니다.

장면 슬라이더는 이제 시작과 끝(또는 없음)에 값 레이블을 표시할 수 있습니다.

장면 슬라이더는 이제 단계 값을 지원합니다.

장면 텍스트는 이제 텍스트 크기를 지정하기 위한 매직 텍스트 값을 지원합니다.

장면 텍스트는 이제 HTML 형식 옵션을 지원합니다.

장면 텍스트는 이제 최대 라인 수와 크기에 맞게 크기 조정 옵션을 지원합니다.

이제 모든 씬 항목이 부울 변수에 바인딩할 수 있는 가시성 상태를 지원합니다.

장면 전환은 이제 별도의 텍스트 색상, 색상 끄기 및 색상 켜기를 지원합니다.

장면 버튼은 이제 부울 변수 토글을 지원합니다.

장면이 작업 블록에서 실행될 때 변수를 정기적으로 업데이트하지 않고 기본적으로 다음 작업 차단 옵션을 사용하지 않는 문제가 수정되었습니다.
